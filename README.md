# 跳蚤越狱实验室

一只跳蚤被关在罐子里，罐口有网。罐里的食物有限，罐外的食物吃不完。每一跳都要花力气，每撞一次网都会受伤、缩短寿命。它该怎么做，才能活得最久？

这个项目把这个问题写成一个**马尔可夫决策过程**，用动态规划精确求出每种处境下的最优选择，并在网页里现场演示。项目从流传很广的“跳蚤跳罐子”寓言出发，延伸到心理学里的**习得性无助**，再加入会变化的网、看守者和跳蚤之间的博弈，以及决策中的**临界点**。

- **交互网页**：[`index.html`](index.html)，单文件，下载后用浏览器直接打开也可以
- **讲解视频**：[`video/flea-video.mp4`](video/flea-video.mp4)，3 分 17 秒，1080p，无配音，配程序生成的背景音乐

## 模型

- **状态**：能量 `e`（0–20）、健康 `h`（0–10）、罐内剩余食物 `f`，以及网的状态 `n`。
- **动作**：吃一份食物、休息（有概率回 1 点血）、轻跳、中跳、全力跳。每个动作都要先付每日代谢。
- **穿网率**：`1 − 网密度^(0.8 × 力度)`。撞网伤害是基础伤害的 1×、1.5×、2×。
- **死亡**：每天的死亡概率 = 基础死亡率 + 伤病系数 × 已损失的健康 + 环境风险（罐内或罐外）。
- **求解**：每个动作要么让食物减少，要么让能量减少，状态之间没有回路。所以按（食物，能量）从小到大做一次贝尔曼递推，就能得到**精确**最优解，不需要近似。
- **目标**：可以选“活得最久”（最大化预期寿命）或“逃出概率最高”。
- **会学习的跳蚤**：对网密度有一个先验分布。每次撞网按似然 `d^(0.8 × 力度)` 做贝叶斯更新，累计撞网力度就是充分统计量。B 型跳蚤还认为网每天有一定概率被拿走，所以“上次撞网后过了几天”也是状态的一部分。

## 一些发现

- **默认条件下**，最优做法是先吃，把能量攒到 9，再全力跳。撞网后先养伤再试。“永远不跳”只能活到最优策略寿命的 45% 左右。
- **要不要跳，主要看罐里和罐外每天的风险差**，而不是罐里还剩多少食物。罐子安全时，最优解是吃到最后一口才跳。
- **食物耗尽时一定要跳**。“永远不跳”在所有场景里都不是最优。
- **看守者**：开网天数相同时，把开网集中起来、推迟到跳蚤撑不到的时候，效果和永远不开一样（逃出率 63.0%，而第一天就开是 98.4%）。不让跳蚤看见网开没开，在开网频繁时很有效。
- **习得性无助**：只会学习、认为“网永远不会变”的跳蚤，撞约 2 次全力跳后就不再跳了。网被拿走后，它有 63% 困死在罐里。只要相信“世界可能会变”，这个比例就降到 8%。停止尝试，也就停止了获取信息（热炉效应）。
- **临界点**：资源是整数、门槛是离散的，所以“差一份食物”可能让寿命从 67 天跳到 179 天。两种做法打平的地方，行为会整个翻转，寿命却几乎不变。

> 关于“跳蚤跳罐子”的故事：它流传很广，但找不到可靠的原始实验记录，更像寓言。“习得性无助”这个概念来自 Seligman 和 Maier 1967 年的狗实验；2016 年两位作者根据神经科学证据修正了解释：被动是长期痛苦下的默认反应，真正需要学会的是“我能控制”。

## 重新生成视频

`video-src/` 里是生成视频用的全部代码。画面在浏览器的 Canvas 里逐帧绘制，音乐用 Web Audio 合成，最后用 ffmpeg 编码。

1. `node video-src/export-data.js video-src`：用模型重新计算视频里用到的数据，写入 `data.json`。
2. `python3 video-src/server.py <ffmpeg 路径> <输出.mp4>`：启动本地服务（端口 8732），接收画面和音频。
3. 在浏览器打开 `http://127.0.0.1:8732/render.html`，在控制台依次运行：
   - `renderAll()`：先合成音乐，再在主线程渲染画面
   - `renderFast()`：用 Web Worker 渲染画面（需要先运行过一次 `renderAll()` 生成音乐）
